DESCRIPCIÓN DEL PROYECTO

Aplicación móvil desarrollada con React Native CLI, TypeScript y Realm DB para registrar libros en una biblioteca personal local.

La aplicación permite agregar libros con título, autor, año y género, listar los libros guardados, realizar búsquedas en tiempo real por título o autor y validar los campos del formulario antes de guardar la información.

El proyecto fue desarrollado tomando como referencia el documento de la actividad ubicado en la carpeta documents/ del repositorio.

Aunque la actividad proponía SQLite como motor de base de datos local, en esta implementación se utilizó Realm DB por su rendimiento, compatibilidad directa con React Native CLI y facilidad para trabajar con objetos tipados en TypeScript.

Como evidencia adicional, se incluye dentro de la carpeta documents/ el archivo default.realm extraído del dispositivo emulado, junto con capturas de pantalla de la aplicación y evidencia de validación de los datos mediante Realm Studio.

SCHEMA DE REALM DB

export class BookRealm extends Realm.Object<BookRealm> {
  id!: string;
  title!: string;
  author!: string;
  year!: number;
  genre!: string;
  createdAt!: Date;

  static schema: Realm.ObjectSchema = {
    name: 'Book',
    primaryKey: 'id',
    properties: {
      id: 'string',
      title: 'string',
      author: 'string',
      year: 'int',
      genre: 'string',
      createdAt: 'date',
    },
  };
}

INSTRUCCIONES DE INSTALACIÓN Y EJECUCIÓN

cd 04_booklist

3. Instalar dependencias:

cd ios
pod install
cd ..
npm run ios


NOTA TÉCNICA

Durante el desarrollo se reemplazó SQLite por Realm DB. Esta decisión mantiene el objetivo principal de la actividad: persistencia local, creación de registros, lectura de datos y búsqueda en tiempo real.

Realm DB trabaja con objetos persistidos y transacciones, por lo que no se construyen sentencias SQL manuales ni se concatenan consultas vulnerables a inyección SQL.
